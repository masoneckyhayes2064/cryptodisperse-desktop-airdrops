## About CryptoDisperse

CryptoDisperse provides desktop users with a centralized workspace for handling airdrop operations across several blockchain environments. Built with Electron, it combines chain routing, automated workflows, and execution monitoring so distribution activities can be coordinated from one application.

The application is intended for Web3 teams and operators managing cryptocurrency distribution on Ethereum, EVM-compatible chains, and Solana. Users can structure execution steps, follow activity as it happens, and retain an audit history while screening and optimization processes are applied throughout the workflow.
